##### Description

<!-- describe what is the question, suggestion or issue and why this is a problem for you. -->

Generated `python` codes have syntax errors when a spec file contains `204 No Content` response.
This is caused by type hint `typing.Union` without any type arguments.

```python
@dataclass
class ApiResponseFor204(api_client.ApiResponse):
    response: urllib3.HTTPResponse
    body: typing.Union[ # syntax error
    ]
    headers: schemas.Unset = schemas.unset
```

(Note: `typing.Union` requires one or more type arguments https://docs.python.org/3/library/typing.html#typing.Union)

##### Suggest a fix

<!-- if you can't fix the bug yourself, perhaps you can point to what might be
  causing the problem (line of code or commit), or simply make a suggestion -->

This type hint should be `schemas.Unset`. Template is intended to render `schemas.Unset` type hint when a body (`content`) is empty.

https://github.com/OpenAPITools/openapi-generator/blob/master/modules/openapi-generator/src/main/resources/python/endpoint.handlebars#L164

However, this is unexpectedly treated as non-empty value because `content`, which is `LinkedHashMap`, is always treated as truthy by conditional blocks `{{#if}}`, `{{#or}}`, and, `{{#and}}`.

- definition of `content` key https://github.com/OpenAPITools/openapi-generator/blob/master/modules/openapi-generator/src/main/java/org/openapitools/codegen/CodegenResponse.java#L92
- handlebars function definition (used for `{{#if}}`, `{{#or}}`, `{{#and}}` blocks):  https://github.com/jknack/handlebars.java/blob/master/handlebars/src/main/java/com/github/jknack/handlebars/Handlebars.java#L200

To fix the issue, we need another way to check whether `content` is empty (adding boolean flag `hasContent` to `CodegenResponse`  class for example).
